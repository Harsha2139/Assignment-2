# 💳 PayFlow Pro

PayFlow Pro is a modern digital payments web application inspired by UPI payment platforms. It provides a responsive dashboard for managing a digital wallet, sending money, mobile recharges, bill payments, and viewing transaction history.

## ✨ Features

- 🔐 User authentication with Supabase
- 👤 User profile management
- 💰 Digital wallet balance
- 📤 Send money using UPI ID
- 📱 Mobile recharge
- 🧾 Bill payment
- 📊 Transaction statistics
- 📈 Transaction activity chart
- 🔎 Transaction search and filtering
- 📋 Recent transaction history
- 📱 Responsive mobile design
- 🖥️ Desktop dashboard
- 🔄 Persistent Supabase sessions
- 🔒 Row Level Security (RLS)
- ⚡ Supabase RPC functions for payment operations
- 🎨 White, green and blue modern UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Supabase
- PostgreSQL
- Supabase Authentication
- Supabase Row Level Security (RLS)
- Supabase RPC Functions
